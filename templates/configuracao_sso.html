Como configurar no Google Cloud Console (Sem custos):

  1. Acesse o Google Cloud Console e crie ou selecione seu projeto.
  2. Vá em APIs e Serviços → Tela de consentimento OAuth e configure para Externo (ou Interno caso use Google Workspace).
  3. Vá em APIs e Serviços → Biblioteca, pesquise por Gmail API e clique em ATIVAR.
  4. Vá em Credenciais → Criar Credenciais → ID do cliente OAuth.
  5. Selecione o tipo Aplicativo da Web.
  6. Em URIs de redirecionamento autorizados, adicione exatamente o endereço abaixo:
{{ redirect_uri }}
